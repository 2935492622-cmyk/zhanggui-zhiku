# 掌柜智库开发规范

## 项目背景
这是一个基于 FastAPI、LangGraph 和 Milvus 的
RAG 智能知识库项目。

## 开发原则
- 优先复用现有模块。
- 不随意更改项目架构。
- 修改前先分析现有实现。
- 每次只处理一个明确任务。
- 修改后运行相关测试。
- 不擅自修改环境变量或数据库数据。
- 不自动执行 git push。

## 教学要求
项目负责人是一名正在学习 AI 应用开发的大学生。

- 解释新增代码的作用。
- 说明重要的技术选择。
- 对复杂逻辑提供简单示例。
- 指出需要掌握的 Python、FastAPI、
  LangGraph、RAG 知识。
- 不要为了完成任务而过度封装代码。
